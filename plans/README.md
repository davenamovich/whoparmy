## Findings considered and rejected

From the same audit — vetted against the live code and rejected, so they
are not re-audited next run:

- **Middleware auth floor is only a cookie-presence check**: by design —
  documented in `src/middleware.ts:10-18`; real session verification
  happens in `lib/auth` (`getWhopUser` throws `UnauthorizedError`).
- **`/api/admin/*` routes look unauthenticated** (no `getWhopUser`):
  all four (gate, stacks/status, launch, grant-credits) are gated by
  `getSessionOperator()` and return 404 to everyone else. Verified by
  reading each route.
- **Swallowed catches in ralph.ts / muse-bridge.ts / mnemos-bridge.ts /
  agent-runner.ts**: spot-read — documented intentional fallbacks (model
  ladder continues, bridge settlement is fail-closed with
  `console.error`, memory is "an enhancement, never a blocker"). The one
  genuinely silent spot — the job dispatch sites — is part of plan 001.
- **`dangerouslySetInnerHTML` in `components/factory/landing.tsx` and
  `components/ui/chart.tsx`**: JSON-LD via `JSON.stringify` of the app's
  own data, and stock shadcn chart CSS injection. Not user-controlled
  sinks.
- **Ralph returns raw LLM text on JSON parse failure**
  (`ralph.ts:441-442`): deliberate fallback so the member still gets an
  answer; the text is the model's reply, not internal data.
